# Родословная - личный семейный архив

Приложение хранит людей, родство, фотографии, документы и рассказы на устройстве. Регистрация и сервер семейных данных не нужны. Реализация следует [единому плану](../plans/2026-11-15-rodoslovnaya-mvp-pwa.md); фактические результаты проверок и открытая приемка телефонов записаны там.

Для работы агента: [инструкции](../AGENTS.md), [маршруты БЗ](../knowledge/INDEX.md), [карта архитектуры](../knowledge/architecture.md) и [журналы проверок](../research-data/README.md). БЗ означает базу знаний проекта; она не содержит семейную базу пользователя.

Вики-ссылки: [[knowledge/INDEX|База знаний]], [[knowledge/architecture|Архитектура]], [[plans/2026-11-15-rodoslovnaya-mvp-pwa|План продукта]].

## Открыть опубликованное приложение

[Открыть «Родословную»](https://rodoslovnaya.152.228.112.185.sslip.io/) - временный HTTPS-адрес на VPS, виртуальном сервере владельца. Первое открытие требует интернета; дождитесь сообщения «Доступно без интернета». Приемка на настоящих телефонах еще не завершена.

На сервер загружена только программа. Семья остается в браузере конкретного устройства. Локальный адрес компьютера и опубликованный адрес имеют разные хранилища: скачайте ZIP-копию на прежнем адресе и восстановите ее на новом. Сам адрес сайта не передает вашу семью другому человеку или устройству.

[Размещение, обновление и откат](../knowledge/hosting.md) описывают эксплуатацию. Доказательства публикации находятся в [журнале размещения](../research-data/deployment-checks-2026-11-17.json).

## Запуск на компьютере

Требуется Node.js 24, среда выполнения JavaScript. Команды выполняются из каталога `app/`.

```powershell
npm.cmd run dev
```

Для проверки установки и работы без сети используйте собранное приложение:

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173
```

Откройте [локальное приложение](http://127.0.0.1:4173), дождитесь сообщения «Доступно без интернета». Первое открытие нового устройства требует сети. PWA означает устанавливаемое веб-приложение; установка и автономность проверяются отдельно.

Обычная чистая установка зависимостей: `npm.cmd ci`. На новом компьютере начните с [корневой инструкции](../README.md#запустите-приложение). Только на рабочем месте владельца `app/node_modules` является соединением каталогов Windows с `D:\CodexTemp\rodoslovnaya-20261115\complete-node_modules`; чистому клону этот путь не нужен. На рабочем месте владельца установка npm может заменить соединение каталогом на C:, поэтому заранее требуется достаточно свободного места. В рамках доработки зависимости не переустанавливались.

## Первый полезный результат

1. Введите имя первого человека. Можно начать с себя или любого родственника; архив получит название «Моя семья».
2. Из карточки нажмите «Добавить родственника», выберите родителя, ребенка или партнера, затем нового человека либо существующего. Перед записью проверьте направление связи.
3. Добавьте фотографию или PDF-документ, напишите историю. Изменить участников и подпись можно в материалах. PDF - формат документов; JPEG, PNG и WebP - поддерживаемые форматы фотографий.
4. Дополнительные сведения раскрываются через «Другие сведения». Даты принимаются как год, год-месяц или год-месяц-день; знак `~` означает приблизительность, например `~1930`. Неизвестная дата остается пустой.
5. Ошибочную связь, человека или материал можно поместить в корзину. Откройте «Архив» → «Корзина», чтобы восстановить группу. Корзина доступна даже без активных людей.
6. В «Архив» → «Копии» скачайте полную копию, найдите файл вне приложения и подтвердите его сохранение. Восстановление создает независимый архив и не объединяет изменения устройств.
7. Для передачи откройте «Семейный выпуск»: выберите людей, затем фотографии и рассказы, проверьте предварительный просмотр и скачайте HTML либо откройте печать. HTML - самостоятельная веб-страница, которой не нужен редактор.

Основные разделы: «Дерево», «Люди», «Материалы», «Архив». На телефоне карточка открывается отдельно, на компьютере рядом с деревом. Корзина и отметки о сформированной копии сохраняются после перезапуска; сам файл нужно сохранить вне приложения. Универсальная отмена изменений в эту версию не входит.

## Сохранность и ошибки

«Сохранено в приложении» означает успешную запись в браузерную базу IndexedDB. Это не подтверждение внешней резервной копии. База зависит от адреса, браузера и профиля: адрес разработки и адрес просмотра имеют разные хранилища.

Неверное поле остается черновиком и не попадает в базу. Можно исправить его или вернуть сохраненное значение только этого поля. При переходе приложение требует явного решения по неверному вводу. Принудительное завершение процесса может потерять незаписанный текст.

При постоянной ошибке записи команда «Скачать сохраненные данные» не пытается записать форму повторно. Она скачивает последний успешно сохраненный снимок; новый несохраненный текст в него не входит. Если сам архив превышает пределы полной копии, открывается аварийное извлечение JSON (структурированные сведения) и отдельных оригиналов. Эти файлы не обозначаются как копия с автоматическим восстановлением.

Пределы обработки: один элемент до 25 МиБ, полная ZIP-копия до 120 МиБ, распакованные данные до 150 МиБ, до 500 элементов с учетом описаний и миниатюр. ZIP - архив файлов; МиБ = 1 048 576 байт. В предел входит также JSON описания проекта. При переполнении доступны извлечение и уменьшение данных; помещение в корзину само по себе не освобождает место.

Навсегда удалить можно только выбранный файловый материал корзины после просмотра последствий. Перед этим доступно скачивание оригинала. Общие материалы не удаляются вместе с человеком; портрет удаленного материала скрывается. Очистка всей корзины и удаление архивов не предусмотрены.

Редактирует одно окно для всех архивов этого адреса. Остальные читают сохраненные сведения. Переход со старой версии базы требует завершить ввод, сохранить внешнюю копию и закрыть старые окна. Новая версия принимает проверенные копии формата 1 и 2, формирует формат 2; старая программа не предназначена для новой базы. Понижение структуры базы автоматически не выполняется.

## Что входит в семейный выпуск

Люди со статусом «Жив» или «Неизвестно» требуют явного включения. Фотографии и рассказы первоначально не выбраны. Подходят только активные материалы, у которых отмечены участники и все они выбраны. Портрет включается только вместе с выбранной фотографией. Корзина, PDF-документы целиком, исходные файлы и скрытая полная база в выпуск не входят.

Изображения заново преобразуются в уменьшенные копии без исходных скрытых метаданных. Упоминания людей в текстах, источнике и групповых фотографиях проверяет редактор. После изменения архива или выбора требуется новый предварительный просмотр.

Полная копия содержит также исключенные из выпуска сведения и оригиналы, поэтому не подходит для выборочной передачи семье. Копии и выпуск не шифруются.

## Проверки и границы поддержки

```powershell
npm.cmd run format:check
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run test:browser -- --timeout=30000
npm.cmd audit --omit=dev
```

Браузерные проверки используют Microsoft Edge на Windows с обычным окном и имитацией телефона. Дополнительные сценарии проверяют ошибочный ввод, отказ записи, корзину последнего человека, сохранение положения дерева, настоящую миграцию старой базы, поиск по 1000 людям и перенос 100 МБ оригиналов. Крупные временные файлы используют каталог системы; при небольшом свободном месте задайте `TEMP` и `TMP` на вместительном диске перед запуском.

Нужно отдельно подтвердить полный путь на настоящих Android и iPhone, включая установленное приложение, обычные фотографии, сохранение и открытие файлов, выпуск и печать у двух близких. Для этого подготовлен опубликованный HTTPS-адрес выше. Обычный HTTP-адрес компьютера в локальной сети не заменяет эту проверку. Следующие публикации требуют отдельной прямой команды.

HEIC - формат фотографий, встречающийся на iPhone. Поддержка обычного системного пути получения такого фото должна быть проверена на устройстве; отдельного преобразователя HEIC нет. Также отложены альтернативные сведения, отдельные источники значений, хронология, импорт GEDCOM (формат обмена родословной), голос, видео, облачная синхронизация и совместное редактирование.
