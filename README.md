# Родословная

«Родословная» хранит людей, родство, фотографии, документы и рассказы на устройстве. Этот репозиторий содержит исходники и базу знаний проекта. Инструкция поможет разработчику запустить приложение и подключиться к совместной работе.

Рабочий кандидат реализован. Приемка на настоящих телефонах и самостоятельное семейное испытание остаются открытыми; см. [текущее состояние](knowledge/CURRENT-STATE.md).

Для установки на чистом компьютере передайте агенту [полную инструкцию Codex](knowledge/INSTALL-CODEX.md). Она включает установку инструментов, получение всего проекта, проверки, первый запуск и дальнейшую работу без аккаунта GitHub.

## Запустите приложение

Для команд ниже нужны Windows, PowerShell, Git и Node.js 24 (среда выполнения JavaScript). Вместе с Node.js устанавливается npm, средство установки зависимостей. Для браузерных испытаний нужен Microsoft Edge: его использует конфигурация проекта.

Клонирование публичного репозитория и локальная работа доступны без учетной записи GitHub.

1. В каталоге для ваших проектов клонируйте репозиторий:

   ```powershell
   git clone https://github.com/TomashPetersen/rodoslovnaya.git rodoslovnaya
   ```

   Каталог `rodoslovnaya` должен отсутствовать.

2. Перейдите к приложению:

   ```powershell
   cd rodoslovnaya/app
   ```

3. Установите версии зависимостей из `package-lock.json`:

   ```powershell
   npm.cmd ci
   ```

4. Запустите сервер разработки:

   ```powershell
   npm.cmd run dev
   ```

5. Откройте адрес из вывода команды. В чистом профиле браузера должен появиться экран «С кого начнем?». Для остановки сервера нажмите `Ctrl+C` в терминале.

Установка на устройство и работа без сети проверяются на собранном приложении; см. [запуск и проверки приложения](app/README.md).

## Подключитесь к совместной работе

Откройте корневую папку `rodoslovnaya` как локальный проект в Codex. Если проект не появился автоматически, добавьте папку в приложении один раз. Клонирование переносит файлы, а сохраненные чаты и настройки приложения остаются на своем компьютере.

Дальнейшие действия описаны в [инструкции совместной работы](knowledge/collaboration.md): отдельная ветка, проверки и PR, то есть запрос на включение изменений в `main`. Для отправки своих веток и создания PR зарегистрируйтесь в GitHub. После регистрации передайте владельцу имя учетной записи, чтобы он мог пригласить вас в репозиторий. Основной путь - доступ на запись по этому приглашению. До приглашения можно работать через fork, собственную копию репозитория на GitHub; для нее также нужна учетная запись. Включение изменений выполняется после проверки владельцем и его прямой команды.

Семейная база браузера, настоящие фотографии и копии, секреты, личные настройки, внешние навыки Codex и `node_modules` не переносятся через этот репозиторий. Зависимости устанавливаются заново. Личная общая база владельца для другого разработчика не требуется.

Начните чтение проекта с [карты знаний](INDEX.md) и [инструкций агента](AGENTS.md). Проверку только базы знаний выполняйте из корня:

```powershell
node scripts/check-knowledge.mjs --self-test
node scripts/check-knowledge.mjs
```
