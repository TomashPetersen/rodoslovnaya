# Проверки базы знаний

Из корня проекта, с Node.js 24 (средой выполнения JavaScript), запустите:

```powershell
node scripts/check-knowledge.mjs --self-test
node scripts/check-knowledge.mjs
```

Первый запуск проверяет положительные и отрицательные примеры самого проверяющего скрипта. Второй проверяет документы проекта; код завершения `0` означает успех, `1` - найденные ошибки, `2` - неверные аргументы. Зависимости устанавливать не нужно, сетевые запросы и изменение файлов не выполняются.

Проверяются корневые файлы Markdown (формат текстовых документов), документы в `knowledge/`, `research/`, `plans/`, `retrospectives/`, `scripts/`, инструкция `app/README.md` и карта материалов `research-data/README.md`. Остальные каталоги внутри `research-data/` не обходятся. Скрипт проверяет существование локальных целей, точный регистр имен, якоря заголовков, выход путей за корень, однозначность вики-ссылок, достижимость каждого документа из корневой карты по обычным ссылкам, длинное тире и поврежденные символы. Ссылки внутри блоков кода, строчного кода и комментариев исключаются. Внешние адреса не открываются; проверка не подтверждает их доступность и достоверность содержания.

## Как записывать ссылки

Обычные ссылки задаются относительно документа. Путь с пробелами заключайте в угловые скобки. Вики-ссылки задаются полным путем от корня проекта к документу базы знаний, без `.md`, с необязательной подписью после `|`. Для перехода к разделу используйте якорь заголовка по правилам GitHub: строчные буквы, пробелы заменены дефисами, знаки препинания удалены; повторные заголовки получают суффикс `-1`, `-2`.

```markdown
[Карта базы](../knowledge/INDEX.md)
[Инструкция с пробелами](<../knowledge/имя файла.md>)
[[knowledge/INDEX|Карта базы]]
[[knowledge/INDEX#раздел|Раздел карты]]
```

Вики-ссылки дополняют обычную навигацию: каждый документ должен быть достижим из [карты проекта](../INDEX.md) по обычным ссылкам. Для исходников, изображений и JSON (формата структурированных данных) используйте обычные ссылки.

## Локальные материалы исследования

Каталоги `research-data/apps/` и `research-data/downloads/` содержат сторонние программы и загрузки, которые не входят в Git. Если документу нужна ссылка на такой локальный материал, используйте обычную ссылку с точным заголовком `"local-only"`:

```markdown
[Локальная программа](../research-data/apps/пример.exe "local-only")
```

Проверка выводит предупреждение о таком материале и не требует его наличия в чистой копии репозитория. Вики-ссылка на него запрещена. Содержимое этих каталогов, `.git/`, `node_modules/`, `output/` и файлы секретов не читаются. Переход по соединениям каталогов и символическим ссылкам не допускается.

Автоматическая проверка не заменяет ручную языковую вычитку измененных документов, проверку фактов и разрешение пользователя на внешнюю отправку. Правила работы с базой определяет [инструкция агента](../AGENTS.md).
